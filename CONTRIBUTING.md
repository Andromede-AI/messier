# Contributing

There are two main ways to contribute:

- Open an issue with a public result source, its paper (if available), and a repository or dataset URL.
- Open a pull request that adds or updates a benchmark builder, or open an issue that flags a problem with an existing one.

See the [builder guide](docs/builders.md) for more details on adding a benchmark. Run `uv run --group dev pytest --source=local` before submitting a change. Maintainers should follow the [publishing guide](docs/publishing.md) when preparing a release.

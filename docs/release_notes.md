## MESSIER v1.0.1

We release the first public version of MESSIER.

- **Corpus.** 903,202 records from 31 benchmarks, 734 agents, 11,999 tasks, and 72,000 verifiers.
- **Data.** The release contains task definitions, results, verifier definitions, and 118,701 available trajectories.
- **Code.** The repository includes dataset builders, loaders, validation checks, IRT models, paper analyses, and the project page.
